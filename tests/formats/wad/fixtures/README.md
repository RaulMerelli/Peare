# WAD fixtures

- `e1m4.wad` — a single level from **FreeDoom** (freely redistributable).
  Source: https://github.com/freedoom/freedoom (levels/e1m4.wad)
- `gfx.wad` — Quake 1.06 shareware WAD2 sample. The local copy is extracted
  from `ID1/PAK0.PAK` in id Software's original shareware distribution. It is
  kept outside this repository. Mirror: https://ftp.gwdg.de/pub/misc/ftp.idsoftware.com/idstuff/quake/quake106.zip
- `decals.wad` — WAD3 sample from the GoldSrc viewer's test assets. The local
  copy is kept outside this repository.
  Source: https://github.com/urgorri/goldsrc-bsp-viewer/tree/main/docs/resources
