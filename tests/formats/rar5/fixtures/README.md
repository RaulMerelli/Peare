# RAR5 GUI Fixture

`rar5-explicit-directories.rar` was created with WinRAR 6.21 from copies of
project-owned `README.md`, `Settings.ini`, and `LICENSE` files. The archive
contains a root file, an empty directory, and nested directories with files.
WinRAR created the RAR5 archive with `Rar.exe a -ma5 -ep1 -r -idq`.
