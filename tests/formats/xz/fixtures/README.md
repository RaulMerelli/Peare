# XZ Reader Samples

7-Zip 19.00 created `docs.tar.xz`, `docs.tar.txz`, and `README.md.xz` with
CRC32 from the project TAR fixture and README. XZ Utils 5.8.3 created the
CRC64, SHA-256, and concatenated-stream variants from the same payloads.
`no-extension.bin` is a byte-for-byte copy of `README.md.xz`.

The ABI test compares the decoded data with the source files. These samples
use project-owned data and are generated by independent compression tools.
