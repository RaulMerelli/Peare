# RAR4 GUI Fixture

`rar4-explicit-directories.rar` was created with WinRAR 6.21 from copies of
project-owned `README.md`, `Settings.ini`, and `LICENSE` files. The archive
contains a root file, an empty directory, and nested directories with files.
WinRAR created the RAR4 archive with `Rar.exe a -ma4 -ep1 -r -idq`.
